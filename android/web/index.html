    同一 Wi-Fi 下的朋友打开本应用就能在上面的列表里看到这个房间；也可以把地址发给他们：

      地址里的 3000 是端口，不能省。访客 Wi-Fi 常开启「AP 隔离」，会导致连不上。

      所有人必须连在同一个服务器上。两台手机都点「建立主机」会得到两个互不相通的游戏，想一起玩就让其中一方用「加入房间」。

      加入房间

      可以直接点上面搜索到的房间；也可以手动输入主机的局域网地址（例如 192.168.1.23:3000），或者粘贴对方发来的链接。
